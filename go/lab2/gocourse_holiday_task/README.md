## Задания
### task_01 - Find

- Функция: ```Find(nums []int, target int) (int, error)```

- Найти индекс числа target в слайсе `nums`

- Если число найдено, вернуть индекс и `nil`

- Если числа нет, вернуть -1 и ошибку(не nil)

Примеры:

```
Find([]int{1,2,3,4}, 4) → 3, nil
```

```
Find([]int{1,2,3,4}, 10) → -1, ошибка
```

### task_02 - FilterEven

- Функция: ```FilterEven(nums []int) []int```

- Возвращает новый слайс, содержащий только чётные числа из nums

- Если нет четных чисел, то нужно вернуть пустой массив(nil-овый)

Примеры:

```
FilterEven([]int{1,2,3,4,5,6}) → [2,4,6]
```
```
FilterEven([]int{1,3,5}) → []
```
!!! Требуется Go 1.21+ для использования пакета `slices.Equal` в тестах, можно проверять вручную через циклы

### task_03 - InsertAt

- Функция: ```InsertAt(nums []int, index int, value int) ([]int, error)```

- Вставляет `value` в слайс `nums` по индексу `index`.

- Если индекс корректный, возвращаем новый слайс и `nil`

- Если индекс отрицательный или больше длины слайса, возвращаем ошибку

Примеры:

```
InsertAt([]int{1,2,3,4}, 2, 15) → [1,2,15,3,4], nil
```
```
InsertAt([]int{1,2,3,4}, 1000, 15) → nil, ошибка
```
```
InsertAt([]int{1,2,3,4}, -1, 15) → nil, ошибка
```

## Как запускать тесты

1. Клонируйте репозиторий и перейдите в папку проекта.

2. Убедитесь, что установлена go версии 1.21 или выше: `go version` в терминале

3. Запуск всех тестов командой: `go test ./...`

4. Запуск каждого теста по отдельности: `cd tasks/task_0x/` (x - номер задания), затем `go test`

5. Тесты проверяют успешные кейсы, пустые слайсы, выход за границы и отрицательные индексы.

6. Если тесты проходят без ошибок, задание выполнено правильно.
